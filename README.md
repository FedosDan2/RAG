## 📝 Обновлённый `README.md` (под адаптивную диагностическую систему)

```markdown
# 🩺 HEALTHVISION — Адаптивный диагностический помощник

> Система задаёт уточняющие вопросы, выбирая самые полезные, и на основе ответов вычисляет наиболее вероятный диагноз.

Проект помогает пользователю предварительно оценить возможное заболевание. В отличие от простого RAG, здесь используется **байесовское обновление вероятностей** и **адаптивный опрос** — каждый следующий вопрос выбирается так, чтобы максимально снизить неопределённость.

## 📁 Структура проекта

```
HEALTHVISION/
├── data/
│   ├── diseases.json      # Список заболеваний (жалобы, ключевые слова, анализы, врачи)
│   └── questions.json     # Вопросы всех типов с вероятностями ответов для каждого диагноза
├── dataset/
│   └── rag_lib_official/   # Кэш FAISS-индексов для быстрого поиска по жалобам
├── detect_objects/         # Модуль извлечения симптомов из текста
├── rag/
│   ├── main_advise.py      # Основной класс консультации
│   ├── rag_offical_lib.py  # RAG-поиск по diseases.json
│   └── diagnostic_session.py # Логика энтропии и выбора вопросов (встроена в main_advise)
├── runner.py               # Точка входа
└── consultation_result.txt # Сохраняется история и итоговый диагноз
```

## ⚙️ Установка и запуск

### 1. Клонируйте репозиторий

```bash
git clone git@github.com:FedosDan2/RAG.git
cd RAG
```

### 2. Установите зависимости

```bash
pip install -r requirements.txt
```

Дополнительно нужен модуль `detect_objects` (ваш внутренний).

### 3. Подготовьте данные

Поместите в папку `data/` два файла:

- `diseases.json` — массив заболеваний с полями:  
  `name`, `complaint`, `keywords`, `required_tests`, `required_doctors`, `question_ids`.
- `questions.json` — массив вопросов с полями:  
  `id`, `text`, `type` (`yes_no`, `single_choice`, `multi_choice`, `scale`),  
  `options`, `applicable_to` (вероятности ответа для каждого заболевания).

Пример минимальной записи вопроса:

```json
{
  "id": "Q001",
  "text": "Есть ли кашель?",
  "type": "yes_no",
  "options": ["Да","Нет"],
  "applicable_to": {
    "Бронхит": { "Да": { "p": 0.9 }, "Нет": { "p": 0.1 } },
    "Грипп":   { "Да": { "p": 0.6 }, "Нет": { "p": 0.4 } }
  }
}
```

### 4. Запустите

```bash
python runner.py
```

Система попросит описать жалобы, затем начнёт задавать вопросы. После каждого ответа вероятности диагнозов пересчитываются.

## 🔧 Как это работает (очень кратко)

1. **Поиск начальных диагнозов** — по жалобам и ключевым словам через FAISS.
2. **Начальные вероятности** — на основе релевантности найденных записей.
3. **Выбор следующего вопроса** — вычисляется **information gain** (снижение энтропии) для каждого ещё не заданного вопроса. Выбирается вопрос, который сильнее всего уменьшит неопределённость.
4. **Обновление вероятностей** — по правилу Байеса с использованием вероятностей ответа из `applicable_to`.
5. **Остановка** — когда уверенность в одном диагнозе превышает порог (например, 70%) или кончились вопросы.
