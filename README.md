# 🩺 HEALTHVISION — Медицинский RAG-советчик на основе симптомов

> **Автономная система медицинской консультации, использующая Retrieval-Augmented Generation (RAG) и кэширование истории запросов.**

Этот проект помогает пользователям получать предварительные медицинские рекомендации на основе описания симптомов. Система объединяет:

- 🔍 Поиск по структурированной базе знаний (RAG),
- 🧠 Генерацию связного совета с помощью локальной LLM (Ollama),
- 📁 Кэширование ответов для ускорения повторных запросов,
- 🇷🇺 Работу полностью на русском языке.

## ⚙️ Установка и настройка

### 1. Установите зависимости

```bash
pip install -r requirements.txt
```

> Если файла `requirements.txt` нет — создайте его с такими пакетами:

```txt
sentence-transformers
faiss-cpu
requests
```

---

### 2. Запустите Ollama (локальный LLM)

Убедитесь, что у вас установлен и запущен [Ollama](https://ollama.com/).

Скачайте модель (например, `llama3:8b`):

```bash
ollama pull llama3:8b
```

Запустите сервер (по умолчанию доступен на `http://localhost:11434`).

---

### 3. Подготовьте данные

Положите вашу медицинскую базу знаний в файл:

```
data/dataset.json
```

Формат записи должен быть примерно таким:

```json
{
  "diagnosis": {
    "objectOfRec": "Острая респираторная вирусная инфекция"
  },
  "complaint": "Высокая температура, кашель, слабость",
  "keywords": "температура, кашель, насморк",
  "recommendations": ["Пить много жидкости", "Постельный режим"],
  "required_tests": ["Общий анализ крови", "Рентген легких"],
  "required_doctors": ["Терапевт", "Инфекционист"]
}
```

## ▶️ Запуск

Просто выполните:

```bash
git pull git@github.com:FedosDan2/RAG.git
cd RAG 
python rag/main.py
```

Скрипт автоматически:
- Загрузит модель эмбеддингов (`intfloat/multilingual-e5-large`),
- Проверит кэш истории,
- Извлечёт релевантные факты из базы,
- Сгенерирует совет через Ollama,
- Сохранит результат в `out.txt`.

## 🔄 Как работает система?

1. **Поиск в истории** — если пользователь задал уже известный запрос, возвращается кэшированный ответ.
2. **Поиск в базе знаний** — если нет, система ищет похожие диагнозы по симптомам.
3. **Генерация промпта** — формируется детальный промпт на русском языке.
4. **LLM-ответ** — отправляется в Ollama, который генерирует читаемый совет.
5. **Сохранение в историю** — ответ сохраняется для будущих похожих запросов.

## 🛠️ Дополнительно
